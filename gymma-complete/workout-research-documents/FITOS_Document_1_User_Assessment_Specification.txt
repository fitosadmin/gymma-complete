ARCHITECTURAL PHILOSOPHY
------------------------
This is NOT a "Workout Form." It is a Fitness Assessment Engine that generates a
User Fitness Profile Vector — a multi-dimensional numerical fingerprint that feeds
the Recommendation Engine. The workout plan is merely the output.

KEY DESIGN DECISIONS:
1. NO EQUIPMENT QUESTIONS. The gym owner pre-filters the global exercise database
   into a Gym Exercise Database. The user never sees "Does your gym have a Smith Machine?"
2. NO SELF-REPORTED EXPERIENCE LEVELS. We calculate an Experience_Score (0-100) from
   behavioral indicators because people lie about being "advanced."
3. SAFETY GATES FIRST. The form is blocked by a medical screening layer derived from
   PAR-Q+ principles.
4. DYNAMIC BRANCHING. A user with <6 months of training answers fewer, simpler questions.
   Advanced users unlock granular inputs (1RM estimates, periodization preferences, split selection).

================================================================================

FORM STRUCTURE & BRANCHING LOGIC
--------------------------------
The assessment is divided into 9 Sections. Each section has Display Conditions
based on previously computed scores.

| Section | Name                  | Purpose                                          | Display Condition                |
|---------|-----------------------|--------------------------------------------------|----------------------------------|
| 0       | Safety Screening      | Medical clearance & contraindications            | ALWAYS (gates the rest)          |
| 1       | Identity & Body       | Demographics, anthropometrics, composition goals   | ALWAYS                           |
| 2       | Recovery Capacity     | Sleep, stress, lifestyle recovery factors        | ALWAYS                           |
| 3       | Training History      | Calculate Experience_Score dynamically           | ALWAYS                           |
| 4       | Goal Specification    | Primary/secondary goals, timeline, target areas  | ALWAYS                           |
| 5       | Availability          | Days, time, schedule constraints                 | ALWAYS                           |
| 6       | Injury & Pain         | Current/past injuries, movement limitations        | ALWAYS                           |
| 7       | Mobility Screen       | Self-reported movement quality                   | If Experience_Score >= 20        |
| 8       | Preferences           | Style, split, liked/disliked exercises           | If Experience_Score >= 35        |

SECTION 0: SAFETY SCREENING (PAR-Q+ Derived)
----------------------------------------------
Purpose: Identify absolute and relative contraindications to exercise before
generating load recommendations. Based on the Physical Activity Readiness
Questionnaire (PAR-Q+), validated for identifying individuals who should undergo
medical evaluation prior to initiating exercise programs.

| Field ID | Question | Data Type | Validation | UI Component | Score Impact |
|----------|----------|-----------|------------|--------------|--------------|
| S0_Q1 | Has a doctor ever said you have a heart condition or high blood pressure? | Boolean | Required | Toggle | If true -> flag CARDIOVASCULAR_RISK |
| S0_Q2 | Do you feel pain in your chest at rest, during daily activity, or during exercise? | Boolean | Required | Toggle | If true -> STOP — refer to medical clearance |
| S0_Q3 | Do you lose balance from dizziness or lose consciousness? | Boolean | Required | Toggle | If true -> STOP — refer to medical clearance |
| S0_Q4 | Do you have a bone or joint problem that could be worsened by exercise? | Boolean | Required | Toggle | If true -> flag MUSCULOSKELETAL_RISK |
| S0_Q5 | Are you currently taking medications for blood pressure or a heart condition? | Boolean | Required | Toggle | If true -> reduce MAX_HEART_RATE cap |
| S0_Q6 | Are you pregnant or have given birth in the last 6 months? | Boolean | Required (if female) | Toggle | If true -> flag PREGNANCY_POSTPARTUM |
| S0_Q7 | Do you have any diagnosed metabolic condition (diabetes, thyroid disorder)? | Boolean | Required | Toggle | If true -> flag METABOLIC_ADJUSTMENT |

BRANCHING LOGIC:
- If S0_Q2 or S0_Q3 is true: Display Medical Clearance Required screen. Allow user
  to proceed to a "Mobility-Only / Light Activity" track but block all load-bearing
  recommendations.
- If S0_Q4 is true: Trigger Section 6 (Injury) automatically and pre-populate INJURY_FLAG.

DATABASE MAPPING: user.safety_screening (JSONB)
MATHEMATICAL IMPACT: Sets hard constraints on MAX_INTENSITY and EXERCISE_BLACKLIST vectors.

SECTION 1: IDENTITY & BODY
--------------------------
Purpose: Establish demographic baselines for metabolic calculation, recovery
expectation, and exercise appropriateness.

| Field ID | Question | Data Type | Validation | UI Component | Score Impact |
|----------|----------|-----------|------------|--------------|--------------|
| S1_AGE | What is your age? | Integer | 15-90, Required | Number input | Affects RECOVERY_CAPACITY and VOLUME_TOLERANCE |
| S1_SEX | What is your biological sex? | Enum (M/F/Other) | Required | Segmented control | Affects LEAN_MASS_ESTIMATE and STRENGTH_STANDARDS |
| S1_HEIGHT | Height (cm or ft/in) | Float | >100 cm, Required | Height picker | Used for BMI and surface area estimates |
| S1_WEIGHT | Current weight (kg or lbs) | Float | >30 kg, Required | Weight picker | Used for relative strength benchmarks |
| S1_BODYFAT | Do you know your approximate body fat %? | Float | 3-60, Optional | Slider | If provided, refines LEAN_BODY_MASS |
| S1_GOAL_WEIGHT | Goal weight (if applicable) | Float | Optional | Weight picker | Determines CALORIC_ADJUSTMENT direction |
| S1_BODY_COMP_GOAL | Primary body composition goal | Enum | Required | Cards | Maps to GOAL_VECTOR |

BODY COMPOSITION GOAL OPTIONS:
- Lose fat (caloric deficit bias)
- Build muscle (surplus bias)
- Recomposition (maintenance bias)
- Maintain current composition (performance bias)
- Improve athletic performance (neuromuscular bias)

MATHEMATICAL IMPACT:
- BMR_ESTIMATE = Mifflin-St Jeor equation using S1_AGE, S1_SEX, S1_WEIGHT, S1_HEIGHT
- LEAN_MASS = S1_WEIGHT * (1 - S1_BODYFAT/100) or estimated via Boer formula
- GOAL_VECTOR is initialized based on S1_BODY_COMP_GOAL

SECTION 2: RECOVERY CAPACITY
----------------------------
Purpose: Quantify lifestyle factors that determine how much training volume a user
can tolerate and adapt from. The American College of Sports Medicine (ACSM) position
stand on progression models emphasizes that individual recovery needs vary based on
age, training experience, and genetics, and that these factors must be accounted for
when prescribing frequency and volume.

| Field ID | Question | Data Type | Validation | UI Component | Score Impact |
|----------|----------|-----------|------------|--------------|--------------|
| S2_SLEEP | How many hours do you sleep on average per night? | Float | 3-12, Required | Slider | Direct input to RECOVERY_CAPACITY |
| S2_SLEEP_QUALITY | How would you rate your sleep quality? | Enum (1-5) | Required | Star rating | Weighted multiplier on S2_SLEEP |
| S2_STRESS | Current stress level (work, life, etc.) | Enum (Low/Med/High) | Required | Segmented control | High stress -> reduce VOLUME_TOLERANCE by 15% |
| S2_OCCUPATION | Is your daily occupation physically demanding? | Enum (Sedentary/Light/Active/Very Active) | Required | Cards | Affects NEAT_ESTIMATE and DAILY_FATIGUE |
| S2_ALCOHOL | Alcohol consumption per week | Integer | 0-21, Optional | Stepper | >7 -> reduce RECOVERY_CAPACITY by 10% |
| S2_NUTRITION | How consistent is your nutrition? | Enum (Poor/Inconsistent/Consistent/Strict) | Required | Cards | Affects PROGRESSION_RATE |

RECOVERY CAPACITY FORMULA:
RECOVERY_CAPACITY = (
  (S2_SLEEP * S2_SLEEP_QUALITY * 4) +
  (Occupation_Factor * 15) +
  (Stress_Inverse * 20) +
  (Nutrition_Factor * 25)
) / 100  ->  clamped to 0-100

JUSTIFICATION: Recovery is the limiting factor for training adaptation. A user sleeping
5 hours with high stress cannot tolerate the same volume as a user sleeping 8 hours
with low stress, regardless of motivation. The ACSM recommends 2-3 days/week for novices
and 4-5 days/week for advanced trainees, but these frequencies assume adequate recovery.

SECTION 3: TRAINING HISTORY (THE EXPERIENCE ENGINE)
---------------------------------------------------
Purpose: Calculate Experience_Score (0-100) objectively instead of asking users to
self-identify. This is the most critical section in the entire form.

WHY NOT ASK "BEGINNER/INTERMEDIATE/ADVANCED"?
Research on training age classification shows that self-reported levels are unreliable.
Many individuals train for years without meaningful progression ("spinning their wheels")
and remain functionally beginners, while others progress rapidly. The ACSM defines novices
as untrained individuals, intermediate as those with ~6 months of consistent RT experience,
and advanced as those with years of RT experience — but we refine this with multi-factorial
scoring.

| Field ID | Question | Data Type | Validation | UI Component | Score Impact |
|----------|----------|-----------|------------|--------------|--------------|
| S3_DURATION | How long have you consistently trained? | Enum | Required | Cards | Primary driver — see table below |
| S3_COMPOUNDS | Can you confidently perform: [Squat, Deadlift, Bench Press, Overhead Press, Pull-up] | Multi-select Boolean | Required | Checklist | Each checked -> +10 points |
| S3_PROGRAM | Have you ever followed a structured workout program? | Boolean | Required | Toggle | true -> +15 points |
| S3_FREQUENCY | How many days did you train consistently in the last 3 months? | Integer | 0-21/week | Slider | Maps to RECENT_ADHERENCE |
| S3_1RM_AWARE | Do you know your approximate 1-rep max for major lifts? | Boolean | Conditional | Toggle | If false -> hide 1RM inputs |
| S3_SQUAT_1RM | Approximate squat 1RM | Float | Optional | Number | If provided -> STRENGTH_RATIO |
| S3_DEADLIFT_1RM | Approximate deadlift 1RM | Float | Optional | Number | If provided -> STRENGTH_RATIO |
| S3_BENCH_1RM | Approximate bench press 1RM | Float | Optional | Number | If provided -> STRENGTH_RATIO |

TRAINING DURATION SCORING:

| Response      | Raw Points | Rationale                                          |
|---------------|-----------|----------------------------------------------------|
| Never         | 0         | True novice — no neuromuscular adaptation          |
| < 6 months    | 15        | Early novice phase — rapid adaptation possible     |
| 6-12 months   | 35        | Late novice — basic motor patterns established     |
| 1-2 years     | 55        | Intermediate — first plateau likely encountered    |
| 2-5 years     | 80        | Intermediate/Advanced — requires periodization     |
| 5+ years      | 100       | Advanced — diminishing returns, complex programming|

COMPOUND LIFT COMPETENCY SCORING:
Each lift checked adds 10 points (max 50). This captures "training age by strength
performance" — a user who has never performed a barbell squat is functionally a beginner
even if they have trained for 2 years doing only machines.

EXPERIENCE SCORE FORMULA:
EXPERIENCE_SCORE = (
  Duration_Points * 0.50 +
  Compound_Points * 0.30 +
  (S3_PROGRAM ? 15 : 0) * 0.15 +
  RECENT_ADHERENCE_Factor * 0.05
) -> clamped to 0-100

DYNAMIC FORM BEHAVIOR:
- If EXPERIENCE_SCORE < 20 (True Beginner):
  * Hide S3_1RM_AWARE and all 1RM fields
  * Hide Section 7 (Mobility Screen) — beginners lack proprioceptive awareness to self-assess
  * Hide Section 8 (Preferences) — beginners need system-determined full-body programs
  * Show simplified "Movement Pattern Familiarity" checklist instead of 1RMs
  * Force SPLIT_TYPE = FULL_BODY
  * Force TRAINING_FREQUENCY = 2-3 days/week

- If 20 <= EXPERIENCE_SCORE < 60 (Intermediate):
  * Show 1RM fields if S3_1RM_AWARE = true
  * Show Section 7 (Mobility Screen)
  * Show split preference (Upper/Lower, Push/Pull/Legs)
  * Recommend TRAINING_FREQUENCY = 3-4 days/week

- If EXPERIENCE_SCORE >= 60 (Advanced):
  * Show all fields including periodization preference (Linear, Undulating, Block)
  * Show advanced split options (Bro split, Specialized, Custom)
  * Show RPE/RIR preference
  * Recommend TRAINING_FREQUENCY = 4-5 days/week

SECTION 4: GOAL SPECIFICATION
-----------------------------
Purpose: Define the target adaptation and map it to the SAID principle (Specific
Adaptations to Imposed Demands).

| Field ID | Question | Data Type | Validation | UI Component | Score Impact |
|----------|----------|-----------|------------|--------------|--------------|
| S4_PRIMARY | Primary training goal | Enum | Required | Cards | Dominates GOAL_VECTOR |
| S4_SECONDARY | Secondary goal | Enum | Optional | Cards | Modulates GOAL_VECTOR |
| S4_TIMELINE | Target timeline | Enum (4/8/12/16/20+ weeks) | Required | Segmented control | Affects PHASE_LENGTH |
| S4_TARGET_AREAS | Specific body areas to prioritize | Multi-select | Optional | Body map | Maps to MUSCLE_PRIORITY vector |

PRIMARY GOAL OPTIONS & EXERCISE MAPPING:

| Goal              | Rep Range Bias | Intensity Bias | Exercise Selection Logic                          |
|-------------------|----------------|----------------|---------------------------------------------------|
| Maximal Strength  | 1-5 reps       | 85-100% 1RM    | Priority: compound barbell movements, low volume, |
|                   |                |                | long rest (3-5 min)                               |
| Hypertrophy       | 6-12 reps      | 75-85% 1RM     | Compounds + isolations, moderate rest (1-2 min),  |
|                   |                |                | multiple sets                                     |
| Muscular Endurance| 15+ reps       | <70% 1RM       | Circuits, supersets, short rest, unilateral work  |
| Power/Explosive   | 1-5 (str) +    | 85-100% +      | Olympic lifts, plyometrics, contrast training     |
|                   | 8-10 (pwr)     | 30-60%         |                                                   |
| General Health    | Mixed          | Moderate       | Full-body, functional movements, cardio integration |
| Body Recomposition| 6-12 reps      | 70-80%         | Hypertrophy-biased with metabolic conditioning    |

JUSTIFICATION: The ACSM position stand explicitly recommends different loading ranges
for different goals: 8-12 RM for novice hypertrophy, 1-12 RM periodized for
intermediate/advanced strength, and 6-12 RM with emphasis on the moderate zone for
hypertrophy.

SECTION 5: AVAILABILITY & CONSTRAINTS
---------------------------------------
Purpose: Determine realistic training volume within the user's time budget.

| Field ID | Question | Data Type | Validation | UI Component | Score Impact |
|----------|----------|-----------|------------|--------------|--------------|
| S5_DAYS | How many days per week can you train? | Integer | 1-7, Required | Stepper | Direct input to FREQUENCY |
| S5_TIME | How many minutes per session? | Integer | 15-120, Required | Slider | Determines SETS_PER_SESSION |
| S5_GYM_TYPE | Where do you train? | Enum (Home/Commercial/Outdoor) | Required | Cards | Filters EQUIPMENT_REQUIREMENTS |
| S5_SCHEDULE | Preferred training days | Multi-select (Mon-Sun) | Optional | Day picker | Used for calendar generation |

AVAILABILITY SCORE:
AVAILABILITY_SCORE = (
  (S5_DAYS * 12) +
  (S5_TIME * 0.5) +
  (Gym_Type_Factor * 10)
) -> clamped to 0-100

SPLIT LOGIC BASED ON DAYS:
- 1-2 days: Full-body only
- 3 days: Full-body or Upper/Lower hybrid
- 4 days: Upper/Lower split
- 5 days: Push/Pull/Legs or Upper/Lower + full body
- 6+ days: Bro split or specialized (advanced only)

SECTION 6: INJURY & MEDICAL HISTORY
------------------------------------
Purpose: Filter the exercise database to exclude contraindicated movements and
trigger regressions. The FMS literature emphasizes that identified movement deficiencies
should guide exercise selection — if a user cannot perform a pattern without compensation,
that pattern should not be loaded until corrected.

| Field ID | Question | Data Type | Validation | UI Component | Score Impact |
|----------|----------|-----------|------------|--------------|--------------|
| S6_CURRENT_INJURY | Do you currently have any injuries? | Boolean | Required | Toggle | If true -> show detail fields |
| S6_INJURY_LIST | Select affected areas | Multi-select (Neck/Shoulder/Elbow/Wrist/Back/Hip/Knee/Ankle) | Conditional | Body map | Populates INJURY_VECTOR |
| S6_PAIN_SCALE | Average pain level during movement (0-10) | Integer | Conditional | Slider | If >3 -> flag LOAD_RESTRICTION |
| S6_PAST_SURGERY | Have you had surgery in the last 12 months? | Boolean | Required | Toggle | If true -> flag POST_SURGICAL |
| S6_PHYSIO | Are you currently seeing a physiotherapist? | Boolean | Required | Toggle | If true -> reduce MAX_INTENSITY by 20% |

INJURY VECTOR MAPPING:
Each body area maps to an EXERCISE_BLACKLIST category:
- Shoulder: Blacklist overhead pressing, kipping pull-ups, dips (if impingement suspected)
- Lower Back: Blacklist loaded spinal flexion (deadlifts, good mornings), allow neutral-spine alternatives (bird-dog, plank)
- Knee: Blacklist deep knee flexion under load (ATG squats, lunges with forward knee travel), allow box squats, hip-dominant movements
- Hip: Blacklist deep squats, allow sumo deadlifts, glute bridges
- Wrist/Elbow: Blacklist barbell work, allow dumbbell/neutral grip

JUSTIFICATION: The FMS approach states that when poor movement patterns are reinforced
through loaded exercise, it increases potential for micro- or macro-traumatic injury.
Therefore, we screen first and load second.

SECTION 7: MOBILITY & MOVEMENT QUALITY (SELF-REPORTED)
-------------------------------------------------------
Purpose: Approximate the Functional Movement Screen (FMS) through self-reporting
to identify movement bottlenecks. The FMS evaluates seven fundamental patterns to
identify asymmetries and limitations that increase injury risk and limit performance.

DISPLAY CONDITION: EXPERIENCE_SCORE >= 20 (users below this lack the body awareness
to self-assess accurately)

| Field ID | Question | Data Type | Validation | UI Component | Score Impact |
|----------|----------|-----------|------------|--------------|--------------|
| S7_SQUAT_DEPTH | Can you squat below parallel with heels down? | Enum (Yes/No/Only with raised heels) | Required | Cards | If "No" -> flag ANKLE_MOBILITY_LIMIT |
| S7_OVERHEAD | Can you raise your arms straight overhead without arching your back? | Enum (Yes/No/Partial) | Required | Cards | If "No" -> flag SHOULDER_MOBILITY_LIMIT |
| S7_HINGE | Can you touch your toes with straight legs? | Enum (Yes/No/Almost) | Required | Cards | If "No" -> flag POSTERIOR_CHAIN_LIMIT |
| S7_LUNGE | Can you perform a walking lunge without losing balance? | Enum (Yes/No/Unstable) | Required | Cards | If "No" -> flag SINGLE_LEG_STABILITY_LIMIT |
| S7_ROTARY | Can you rotate your torso 45+ in each direction without pain? | Enum (Yes/No/Limited) | Required | Cards | If "No" -> flag TRUNK_ROTATION_LIMIT |

MOBILITY SCORE:
MOBILITY_SCORE = (
  (S7_SQUAT_DEPTH == 'Yes' ? 25 : S7_SQUAT_DEPTH == 'Only with raised heels' ? 15 : 5) +
  (S7_OVERHEAD == 'Yes' ? 25 : S7_OVERHEAD == 'Partial' ? 15 : 5) +
  (S7_HINGE == 'Yes' ? 20 : S7_HINGE == 'Almost' ? 12 : 5) +
  (S7_LUNGE == 'Yes' ? 20 : S7_LUNGE == 'Unstable' ? 10 : 5) +
  (S7_ROTARY == 'Yes' ? 10 : 5)
) -> clamped to 0-100

EXERCISE REGRESSION MAPPING:
- ANKLE_MOBILITY_LIMIT < 20 -> Replace back squat with box squat or goblet squat; replace conventional deadlift with sumo or trap bar
- SHOULDER_MOBILITY_LIMIT < 20 -> Replace overhead press with landmine press; replace pull-up with neutral-grip lat pulldown
- POSTERIOR_CHAIN_LIMIT < 20 -> Replace Romanian deadlift with glute bridge; add daily hamstring mobility work
- SINGLE_LEG_STABILITY_LIMIT < 20 -> Replace Bulgarian split squat with supported split squat; add balance work

JUSTIFICATION: The FMS uses a 0-3 scoring system per movement where a score of 2 or
less indicates compensatory patterns. In our self-reported model, a "No" or "Unstable"
answer approximates an FMS score of 1-2, indicating that loaded versions of that pattern
should be discontinued until corrected.

THE USER FITNESS PROFILE VECTOR
-------------------------------
Once all sections are complete, the form outputs a User Fitness Profile Vector —
an 8-dimensional numerical fingerprint:

{
  "Goal_Alignment": 0-100,        // Derived from S4 (Primary + Secondary goals)
  "Recovery_Capacity": 0-100,     // Derived from S2 (Sleep, stress, nutrition, occupation)
  "Mobility_Score": 0-100,         // Derived from S7 (Self-reported FMS approximation)
  "Strength_Level": 0-100,         // Derived from S3 (1RM ratios or bodyweight benchmarks)
  "Experience_Score": 0-100,      // Derived from S3 (Duration + compounds + program history)
  "Availability_Score": 0-100,     // Derived from S5 (Days * time * gym type)
  "Injury_Risk": 0-100,           // Derived from S0 + S6 (Contraindications + current injuries)
  "Preference_Alignment": 0-100     // Derived from S8 (Style, split, cardio, dislikes)
}

HOW THIS VECTOR MAPS TO EXERCISE SELECTION:
The Recommendation Engine compares the User Vector against every exercise in the
Gym Exercise Database (pre-filtered by the gym owner). Each exercise has its own
Exercise Profile Vector:

{
  "Exercise_ID": "EX-001",
  "Name": "Barbell Back Squat",
  "Difficulty": 65,               // 0-100
  "Muscle_Groups": ["Quads", "Glutes", "Core"],
  "Mobility_Requirements": {
    "Ankle": 25,
    "Hip": 30,
    "Shoulder": 0
  },
  "Injury_Risk_Factor": 45,      // Higher = more contraindications
  "Goal_Compatibility": {
    "Strength": 95,
    "Hypertrophy": 85,
    "Endurance": 40
  },
  "Equipment": ["Barbell", "Squat_Rack"],
  "Experience_Minimum": 35
}

MATCHING ALGORITHM (Simplified):
MATCH_SCORE = (
  Goal_Compatibility[User.Goal] * 0.30 +
  (100 - |Difficulty - Experience_Score|) * 0.25 +
  (Mobility_Requirements <= User.Mobility_Score ? 100 : 0) * 0.20 +
  (Injury_Risk_Factor <= User.Injury_Risk ? 100 : 0) * 0.15 +
  Preference_Alignment * 0.10
)

Exercises are ranked by MATCH_SCORE and assembled into the workout plan based on
Availability_Score (determines volume) and Recovery_Capacity (determines frequency
and intensity).

-----------------------

| Design Decision                        | Scientific Basis                                      |
|----------------------------------------|------------------------------------------------------|
| PAR-Q+ screening before exercise       | Pre-participation screening identifies contraindications;|
|                                        | high sensitivity for cardiovascular risk             |

|                                        | different training ages and goals                    |

| strength                               | hypertrophy, high (15+) for endurance                |
